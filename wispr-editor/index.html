Don’t edit. Just say it.

A video editor you drive by talking. Record yourself with a teleprompter that follows your voice, add a screen take whenever you like, then say what to change. Claude makes the edit on the timeline while you watch.

Install in one commandWatch what it made
1

Record like you talk

The teleprompter lights up each word as you say it and only moves on once you finish the line. It never runs on a timer. Space or → if you want to jump.

Camera and screen are separate tracks. Record them together, or do the screen pass later and drop it in at the playhead.

Being fixed: on some Macs voice-follow goes quiet while the camera is recording, because both want the mic. Space and → always work.

2

Say the edit

  • “Cut the pauses and the ums.”
  • “Put the challenge page over the second line.”
  • “Show the site full while I talk about it.”
  • “Make the captions bigger, one word at a time.”

Type it, dictate it with Wispr, or say it to Claude Code. The timeline updates live.

3

Export everywhere

9:16 for Reels, 4:5 for the feed, 16:9 for YouTube. Word-timed captions with your keywords highlighted are burned in by ffmpeg, all on your Mac.

Speech-to-text runs on-device with whisper.cpp. Your footage never leaves the machine.

How Claude edits it

The project is a plain JSON edit list. Claude reads it (clips, script lines, every word with its time) and sends ops back through a small MCP server. The editor watches the file, so you see each change land.

video_edit({ ops: [
  { "op": "cut_silences", "min_gap": 0.45 },
  { "op": "overlay", "src": "challenge-page", "start": 5.49, "end": 20.66,
    "box": { "x": 0.08, "y": 0.12, "w": 0.84, "h": 0.46 }, "fit": "contain" },
  { "op": "captions", "size": 0.055, "words": 3 },
  { "op": "keywords", "add": ["Wispr", "2,000"] }
]})

Try it yourself

One command. Nothing is installed or written to your settings until you keep it.

claude --plugin-url https://sameep.ai/wispr-editor/wispr-video.zip

Then type /video. Needs macOS, Chrome for the teleprompter’s voice-follow, ffmpeg, and whisper-cpp (brew install ffmpeg whisper-cpp). Projects live in ~/WisprVideo.
